# Roadmap

These are planned areas, not delivered features or release-date promises.

- **Distribution trust:** Developer ID signing and notarization; automatic update delivery with verified downloads.
- **Concurrency and boundaries:** migrate to strict Swift 6 isolation, split import/playback coordination from `LibraryStore`, and document ownership for remaining system-framework handoffs.
- **Physical compatibility:** a repeatable DAC/sample-rate matrix, real AirPlay receiver checks and disconnect/reconnect tests on multiple NAS implementations.
- **Usability:** a complete VoiceOver audit, more keyboard workflows, and manual verification across light/dark and accessibility display settings.
- **Library refinement:** album-artist and compilation metadata support beyond the current first-artist heuristic, and guided backup restoration.

Current limits and actual evidence are recorded in [VALIDACION.md](../VALIDACION.md).
