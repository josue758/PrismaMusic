# Material de lanzamiento — borradores

Estos textos están preparados para revisión; no se han publicado en redes. No hay garantía de alcance o viralidad. El instalador público sigue siendo beta con firma ad hoc; no anunciarlo como notarizado hasta completar y verificar el proceso de Apple.

## Texto para una publicación de portafolio

Estoy desarrollando Prisma Music, un reproductor nativo para macOS con Swift y SwiftUI. Trabaja con bibliotecas locales y NAS, permite elegir una salida Core Audio y tiene una sala de escucha con carátula y letras, incluida traducción al español mediante Apple.

En el repositorio documento las decisiones sobre cargas lentas, cancelación, persistencia y audio. También incluye pruebas y una validación automática que genera y verifica el instalador.

Busco comentarios sobre la experiencia y oportunidades para seguir creciendo en desarrollo de software para macOS.

Código, documentación y beta: https://github.com/josue758/PrismaMusic

## Guion de demostración de 30 segundos

- 0–5 s: abrir la biblioteca y un álbum; mostrar que las canciones están ordenadas.
- 5–12 s: abrir la sala de escucha independiente y mostrar la carátula.
- 12–20 s: mostrar letra original/traducción con archivos que puedas compartir; para audio, usar las demos incluidas u otro material autorizado.
- 20–26 s: mostrar selector de dispositivo e inspector de formato, bitrate y profundidad. No afirmar certificación física bit-perfect.
- 26–30 s: cerrar con el repositorio, la descarga y una pregunta concreta de feedback.

Antes de compartir capturas, revisar que no contengan rutas privadas, nombres del NAS, credenciales ni archivos personales. Mantener los créditos de imágenes utilizados.
